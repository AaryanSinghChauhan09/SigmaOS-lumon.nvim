# SigmaOS Lumon.nvim

Neovim configuration inspired by the Lumon interface from Severance.

## Overview

SigmaOS Lumon.nvim provides a unique Neovim configuration with a Lumon-inspired theme and interface elements.

## Features

- Lumon-inspired color scheme
- Custom interface elements
- SigmaOS integration
